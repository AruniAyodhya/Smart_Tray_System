# Smart_Tray_System
This project uses YOLOv8 object detection to identify Sri Lankan canteen food items from images. The system was trained on a custom annotated dataset containing 8 food categories.

## Food Classes
- Chicken Bun
- Chicken Cutlet
- Chicken Pastry
- Chicken Rolls
- Chicken Rotti
- Iced Coffee
- Milk Rice
- Pizza - Cheese Lovers
